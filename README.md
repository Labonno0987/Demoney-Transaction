# Demo User Transactional Management 
## Description:
 By this demo API project named dmoney, we can ensure a seamless and efficient process for user(Customer,Agent,Merchant) creation, fund transfers, withdrawals, and payments across different account types. This includes maintaining accuracy in balance updates, validating transactions, and ensuring a smooth financial workflow at every step.

## Technology I used:
- Postman
- Newman
- Report: newman-html-extra

## URL for Postman documentation
  https://documenter.getpostman.com/view/42734956/2sAYdmk813
 
## How to run?
- Clone this project
- Collect .env from developer and put on the source root folder
- Hit following command:
  - ``` npm i```
  - ``` npm test```
- Report will be generated in Reports folder
